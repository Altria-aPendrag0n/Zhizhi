## P0-1 本地端到端走查（上线决策前应补）

S8 后的本地阶段完成标志，尚未正式走查过：

1. 本地起服务端（LogNotifier 模式取码）→ 注册 → 登录 → 注册赠送额度到账；
2. 管理台生成兑换码 → 客户端兑换 → 套餐生效（模型分组切换）→ 对话实时扣费 → 用量图表刷新；
3. 忘记密码重置 → 旧会话失效；注销账号 → 数据匿名化；
4. 走查发现的缺陷修复后勾销本项。
