## 1. 功能一：来源锚定（引用回溯）

### 1.1 数据基础（已存在，无需新建）

- 检索命中 `KnowledgeHit`（`src/utils/knowledge-retrieval.ts:39-56`）已含 `kind / path / title / snippet / pageFrom / pageTo / sectionTitle / pageCount`；
- 注入文本由 `buildKnowledgeContext()`（`knowledge-retrieval.ts:223-252`）生成，当前格式为 `### [笔记] {title}` / `### [参考资料] {title}`；
- 渲染管线：流式期 `StreamText.vue`（简易正则）、最终消息 `ChatMessage.vue:61-66`（marked）+ 渲染后处理（`applyMarkLinks` 先例）；
- 会话持久化已有 HTML 注释块先例：`<!-- thinking -->`（0.1.1 引入）。

### 1.2 设计

**注入侧（T1）**
- `buildKnowledgeContext()` 改造：来源条目按序编号，标题行改为 `### [1] [笔记] {title}` / `### [2] [参考资料] {title}（第 x-y 页）`；函数返回值从 `string` 升级为 `{ context: string, sources: CitationSource[] }`；
- `CitationSource = { index: number, kind: 'note' | 'reference', path: string, title: string, pageFrom?: number, pageTo?: number, sectionTitle?: string, snippet: string }`；
- system prompt 追加引用约定段：「回答中引用上述来源内容时，在对应句子末尾标注 `[编号]`；未在来源列表中的信息不要编造编号」。

**持久化侧（T2）**
- AI 消息落盘时在 `<!-- thinking -->` 同级追加 `<!-- citations: <JSON> -->` 块，保存本次消息的 `CitationSource[]`；
- 会话加载时解析回内存，历史消息的来源列表可恢复；
- 流式期间不落 citations，消息定稿（写入 vault）时一并写入。

**渲染侧（T3）**
- 校验纯函数 `resolveCitationMarkers(text, sources)`：正则提取正文 `[n]`，仅保留 `1 ≤ n ≤ sources.length` 的编号，其余原样——防编造/越界；
- `ChatMessage.vue` 渲染后处理阶段（`applyMarkLinks` 同层）把合法 `[n]` 替换为角标元素（sup 样式，点击打开浮层）；
- 消息底部渲染来源列表组件 `CitationList.vue`：序号 + kind 图标 + 标题 + 页码/章节 + snippet（截断）；
- 点击角标/条目 → `CitationPopover` 浮层：完整 snippet、页码区间、「打开原文」按钮；
  - 笔记来源 → 跳笔记详情路由；
  - PDF 来源 → 打开轻量原文查看浮层（`read_reference` 按页提取文本展示该页，标注页码；现状无按页阅读 UI，新建该组件，纯文本渲染即可）；
- 角标样式需兼容划线摘录（`applyMarkLinks`）与 Mermaid 渲染的既有后处理顺序。

**分支会话接入（T4）**
- `branch-followup.ts:84-86` 拼接 knowledgeContext 处改为接收新返回结构，system prompt 追加同一引用约定段；
- 分支 AI 消息同样落 `<!-- citations -->` 块，`BranchChatPage` 复用 T3 的渲染组件。

### 1.3 明确不做

- 复习页面不加角标（有自己的反馈体系）；
- 不做句级结构化引用（citations 数组），不做 PDF 原生渲染。

## 2. 功能二：引导模式（Khanmigo 式伴读）

### 2.1 设计

**状态与开关（T5）**
- 全局默认：settings store 新增 `guideModeDefault`（常规设置面板，开关 + 说明文案「多轮引导讲解，token 消耗更高」）；
- 会话级：主会话工具栏新增「引导模式」切换按钮（点亮态显示），会话内即时生效；
- 持久化：引导状态写入会话 frontmatter（`guide: true/false`），恢复会话时还原；未标注的旧会话按全局默认初始化。

**提示词（T5）**
- 新增 `SYSTEM_PROMPT_GUIDED` 变体，在现有 `SYSTEM_PROMPT` 基础上追加引导策略段：
  1. **诊断起点**：讲解前先了解用户基础与目标（零基础回答合法，据此校准起点）；
  2. **小步讲解**：每次只推进一个概念点，篇幅克制，不一次性输出完整长文；
  3. **检查点**：每个节点以确认问题收尾（「跟上了吗 / 用你自己的话说说」）；
  4. **让学生产出**：适时请用户复述或应用，AI 校验理解后再推进；
  5. **逃生约定**：用户明确表示要直接答案（如「直接告诉我」「不想猜了」）时，立即切直接讲解，不再追问；
  6. RAG 注入的知识上下文照常使用：诊断时参考用户笔记与资料，讲解时优先引用；
- 引导模式下输出同样带来源角标（与功能一共用注入与渲染，无额外工作）。

**分支会话（T6）**
- `branch-followup` skill 增加引导段（SKILL.md body 增加 `{guide_mode}` 可选段：非引导时替换为空串），分支页读取会话 `guide` 状态决定是否注入；
- 分支页工具栏同样提供会话级切换。

### 2.2 明确不做

- 不做「直接给我答案」按钮（逃生走提示词约定）；
- 不接入 review-quiz 结构化变式出题（复述/应用检查由提示词内的自然语言完成）；
- 不做引导效果的数据统计。

## 3. 任务拆分（按依赖顺序，逐任务测试通过后提交）

| # | 任务 | 类型 | 关键产物 | 验收 |
|---|------|------|----------|------|
| T1 | knowledge-retrieval 编号注入与来源映射 | 开发 | `buildKnowledgeContext` 返回 `{context, sources}`；system prompt 引用约定段 | 单测：编号顺序、pdf 页码条目、空来源、预算截断不破坏编号 |
| T2 | citations 会话持久化 | 开发 | `<!-- citations: JSON -->` 写入与解析；消息类型扩展 | 单测：写入/解析往返、旧会话无块兼容 |
| T3 | 角标渲染 + 来源列表 + 浮层 | 开发 | `resolveCitationMarkers` 纯函数；`CitationList.vue`；`CitationPopover.vue`；PDF 原文查看浮层（read_reference 按页）；ChatMessage 后处理接入 | 单测：合法/越界/编造编号过滤；组件测试：浮层交互、跳转事件 |
| T4 | 分支会话接入锚定 | 开发 | branch-followup 注入新结构；BranchChatPage 渲染与落盘 | 组件测试：分支消息角标与来源列表 |
| T5 | 引导模式主会话 | 开发 | `SYSTEM_PROMPT_GUIDED`；settings 全局默认；会话级开关 UI；frontmatter 持久化 | 单测：提示词变体拼接；组件测试：开关状态与恢复 |
| T6 | 引导模式分支会话 | 开发 | SKILL.md `{guide_mode}` 段；branch-followup 注入；分支页开关 | 单测：guide 开/关两种 prompt 构建结果 |
| T7 | 文档与发布 | 开发 | code-wiki 02/08/09 号文档补充；CHANGELOG；README 特色段更新 | 文档与实现一致 |

**全局验收标准**
- 主/分支会话中，回答引用检索来源处出现可点击角标，浮层可预览并跳转原文（笔记详情 / PDF 按页文本）；
- 编造或越界编号不渲染为角标；
- 重启应用后历史消息来源列表与角标可正常恢复；
- 引导模式开启后：先诊断后讲解、小步推进、有检查点；输入「直接告诉我」立即得到直接讲解；
- 引导开关状态跨重启恢复；默认值取设置页；
- 全量测试通过，smart 截图/文档同步更新。

## 4. 风险与开放问题

1. **角标与既有后处理的顺序冲突**：`applyMarkLinks`（划线标记）与角标替换都作用于渲染后 DOM，需固定执行顺序并补回归测试（划线文本内含 `[1]` 的边界用例）；
2. **流式期间的角标体验**：流式中 `[1]` 为纯文本，定稿后才变角标——视觉上会有一次跳变，接受；若体验差再优化；
3. **LLM 编号漂移**：提示词约定法不能保证 100% 编号正确，校验层兜底后最坏表现为「该标没标」，不会出现「错误指向」；
4. **PDF 原文查看浮层为新增组件**：纯文本按页展示（复用 `read_reference` 管线），不做原生 PDF 渲染——若后续需要再升级；
5. **引导模式 token 成本**：多轮小步讲解天然更高，开关旁 tooltip 明示；观察上线后用量再决定是否做「提示词压缩」。
