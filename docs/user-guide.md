## 1. 知枝是什么

知枝是一款 **AI 伴读桌面应用**。它把学习过程拆成几个可沉淀、可检索、可回顾的环节：

- **学习会话**：与 AI 对话学习一个新概念；
- **原子笔记**：从 AI 回答中划选关键内容，提炼成一张张小卡片笔记；
- **间隔复习**：笔记到期后按记忆规律自动安排复习，把短时记忆变成长期记忆；
- **学习地图**：集中处理到期复习、查看学习节奏；
- **学习总览**：每天/每周学了什么、学了多少，一目了然。

所有数据都保存在**你自己的本地文件夹（Vault）**里，不会上传到任何服务器。

## 2. 安装与首次启动

1. 双击安装包（Windows 下为 `.msi` 或 `.exe`），按向导完成安装。
2. 从开始菜单或桌面快捷方式启动「知枝」。
3. 首次启动会弹出欢迎引导，展示三步配置指引（本手册第 3 节），可直接关闭或点击按钮前往设置。
4. 若 Windows 提示"已保护你的电脑"（SmartScreen）：测试版安装包尚未签名，点击「更多信息 → 仍要运行」即可。

> **系统要求**：Windows 10 1809 及以上（内置 WebView2）。macOS / Linux 版需在对应平台构建分发。

## 3. 三步快速上手

### 第 1 步：选择你的学习库（Vault）

进入「设置」→「学习仓库」：

- **打开 Vault**：选择已有的学习目录（推荐新建一个空文件夹，例如 `D:\learning`）；
- **新建 Vault**：选择父目录并输入名称，知枝会自动创建 `notes/`、`sessions/`、`attachments/` 等子目录；
- 之后可在设置里随时切换或关闭 Vault，最近打开过的会列在下方。

> Vault 是知枝唯一的"家"。笔记、会话、复习记录都存放在这里。

### 第 2 步：配置 AI 服务商

仍在「设置」页面，配置：

| 配置项 | 说明 |
|--------|------|
| 服务商 | Anthropic (Claude)、OpenAI、DeepSeek、通义千问、智谱 (GLM)、Ollama（本地）或自定义 |
| API 地址 | 选择服务商后自动填充，一般无需修改 |
| API Key | 粘贴你的密钥（点击右侧眼睛图标可显示/隐藏） |
| 模型名称 | 选择具体模型，如 `gpt-4o`、`claude-sonnet` 等 |

填好后点「保存设置」，再点「连接测试」确认能正常对话。若提示失败，检查 Key 是否有效、网络是否可达。

### 第 3 步：开始第一次学习

1. 回到「学习会话」，点击「新建会话」（或快捷键 `Ctrl+N`）；
2. 输入一个问题，例如"用费曼学习法解释工作记忆"；
3. 在 AI 回答上**划选**一段关键内容，选择「摘录为笔记」；
4. 在「资料库」查看你的笔记；当天稍后或第二天，到期笔记会出现在「学习地图 → 复习」里。

至此，你已经走完了"对话 → 笔记 → 复习"的完整学习闭环。

## 4. 核心概念

| 概念 | 说明 |
|------|------|
| **Vault（学习库）** | 一个本地文件夹，知枝的全部数据都存放在这里 |
| **学习会话** | 与 AI 的一次对话；支持从任意消息**分叉出分支**做深度追问 |
| **原子笔记** | 从 AI 回答划选提炼的小卡片笔记，含类型、标签、原文与你的理解 |
| **参考资料** | 上传的 PDF / Markdown / 图片，供对话时检索引用 |
| **复习** | 到期笔记按间隔重复（SRS）算法安排复习，支持经典间隔与 FSRS 个性化两种算法 |
| **学习地图** | 复习任务的入口；「认知地图」视图仍在开发中 |
| **学习总览** | 主界面（点击左上角知枝图标进入）：累计问答/复习/笔记、连续学习天数、学习频率格子图 |

### 常用快捷键

| 快捷键 | 动作 |
|--------|------|
| `Ctrl + N` | 新建会话 |
| `Ctrl + ,` | 打开设置 |
| `Ctrl + B` | 打开资料库 |
| `Ctrl + H` | 打开学习地图 |

## 5. 界面导览

应用窗口分几部分：

- **最左侧项目栏**：知枝学习（对话）/ 资料库（笔记）/ 学习地图（复习）；
- **会话列表**：当前项目的会话与分支；顶栏可收起；
- **主内容区**：根据所在页面显示对话、笔记、复习或设置；
- **顶栏**：面包屑、返回按钮、设置按钮与更多操作菜单。

窗口支持缩放（最小 1024×700）；窗口较窄时会话列表自动收起为抽屉，可点左上角按钮展开。

## 6. 数据存放与隐私

### 6.1 你的数据存在哪里

| 数据类型 | 位置 |
|----------|------|
| 笔记（Markdown） | `<Vault>/notes/*.md` |
| 学习会话 / 分支 | `<Vault>/sessions/*.md` |
| 参考资料 | `<Vault>/references/` |
| 复习队列、会话树等元数据 | `<Vault>/.study-thread/` |
| 应用设置（含 API Key）、最近 Vault | 应用本地存储（WebView localStorage） |

### 6.2 隐私承诺

- **数据不自动上传**：笔记、会话、参考资料、复习记录都保存在本地 Vault，知枝不会收集或上传这些内容；
- **对话内容**仅在你配置的服务商处处理：发送问题给 AI 时，内容会经由你选择的 LLM 服务商（Anthropic / OpenAI / DeepSeek 等）处理，请留意各家服务的隐私政策；
- **AI 联网搜索**：设置中开启「联网搜索」后，模型可能访问互联网检索信息；
- **API Key** 保存在应用本地存储中（明文），请勿将电脑借给他人使用，或与他人在共享设备上使用。

### 6.3 备份与卸载

- **备份**：复制 Vault 文件夹即可完整备份全部学习数据；
- **卸载**：卸载应用**不会**删除 Vault 文件夹，数据会保留在磁盘上。

## 7. 常见问题（FAQ）

**Q1：不配置 API Key 能用吗？**
多数核心功能（对话、摘录笔记、复习出题）依赖 AI 服务，需要配置 API Key。复习功能在无 Key 时仍可进入"原文模式"（直接展示笔记原文复习）。

**Q2：对话提示"fetch failed"怎么办？**
多为网络问题。检查：API 地址与 Key 是否正确、网络/代理是否可达目标服务商。更换服务商或稍后重试。

**Q3：为什么笔记检索没反应？**
首次使用会加载内置的本地向量模型（约 60MB，随应用安装），加载完成前知识检索暂不可用，不影响对话本身。

**Q4：可以换 Vault 吗？**
可以。设置 →「学习仓库」→「切换 Vault」。切换后学习总览与复习队列会基于当前 Vault 重新统计。

**Q5：数据会同步到云端吗？**
不会。知枝是纯本地应用，无账号、无云同步。如需多设备，请手动复制 Vault 目录。

**Q6：这是正式版吗？**
不是。当前为 v0.1 测试版，功能与数据格式仍在迭代，可能出现界面变化或问题。

**Q7：卸载后重装，数据还在吗？**
Vault 数据保留（见 6.3）。应用设置（如 API Key）随应用数据删除，需重新配置。

## 8. 反馈问题与建议

你的反馈对测试版迭代非常重要。反馈前请先准备上下文：

1. 打开「设置 → 关于知枝」，点**「导出调试日志」**保存日志文件；
2. 或点**「复制反馈信息」**，把版本、平台与最近日志复制到剪贴板；
3. 连同**问题描述**（做了什么、期望什么、实际发生了什么）一起发送给知枝团队。

> 请务必带上版本号与日志，否则我们很难定位问题。
