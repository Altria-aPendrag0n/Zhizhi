## v0.3.0

学习计划 Agent + 未来一周复习时间轴 + 知枝官方账号与官方通道。

### 新增

**学习计划（AI 规划师）**

- plan-architect 规划师 Agent：访谈式对话收集目标、基础与每日可用时间，生成「目标 → 阶段 → 每日任务」学习计划
- 计划以 Markdown 落盘 `<Vault>/plans/`，支持手动修改与整体重新生成
- 学习地图新增计划视图：今日任务按每日容量动态顺延、「开始学习」直达会话并回填任务关联、阶段与整体预计完成日
- 侧边栏学习 / 计划会话分组独立折叠；首页提供计划任务入口

**复习时间轴**

- 复习视图新增未来一周时间轴：7 天横向卡片、今天高亮、逾期归今天标注、条目点击直达笔记（回看不触发调度）

**知枝官方账号与官方通道（可选）**

- 邮箱验证码注册、用户名密码登录；「记住密码」重启自动续期，凭据仅存操作系统钥匙串
- 模型配置一键切换官方 / 自定义；官方通道支持对话模型下拉选择，当前模型失效自动切换
- 账号页整合套餐 / 额度展示；忘记密码重置与注销账号

### 修复

- 官方 Key 缺失自动补发自愈，修复空凭据导致发消息失败
- 修复确认框失效（dialog 权限）与设置子页面布局错乱
- 修复学习计划向导空态无法输入

---

**安装**：下载 `Zhizhi_0.3.0_x64-setup.exe`（推荐）或 `Zhizhi_0.3.0_x64_zh-CN.msi`；已安装用户可在设置页「关于知枝」→「检查更新」自动升级。

> 测试版安装包未签名，SmartScreen 提示时点击「更多信息 → 仍要运行」即可。
